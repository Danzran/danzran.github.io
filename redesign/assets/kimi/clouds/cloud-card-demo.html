Fluffy cloud card containers

Three ways to put a cumulus edge around a card of any size. Resize the window: every card below holds real text and stretches with it.

A. 9-slice border-image from a Codex frame (recommended)

Uses cloud-frame-square.webp (keyed to alpha). The corners stay painted; the edges repeat with round. Slice 215 sits just inside the flat centre, so the panel has no seams. This keeps the painted look closest, holds up from 240px to 560px wide, and costs one image (~100 KB). On very long cards the repeated edge puffs can show a rhythm. The panel tint is the painting's #ebf0fa.

B. Pure-CSS scallop mask

Circles repeated along each edge with mask, plus a drop-shadow rose rim. No image, any size, very cheap. It reads as tidy scallops rather than painted cumulus: good for small chips and tags.

C. SVG puffs + filter (procedural fallback)

A small script lays random-radius circles round the card's edge (re-run on resize via ResizeObserver, seeded so it is stable). An SVG filter adds turbulence wobble, lavender undersides and a rose rim. Any size, organic, no image weight; the centre is a flat panel colour for text.
