Scribble: lines that mutate instead of swap

Every frame, each point on the glyph outline is pushed along its normal by smooth multi-octave noise in (x, y, time). The noise phase drifts, so bumps crawl along the edges and nothing pops between drawings. The old v8 boil, which swapped 3 drawings per letter at 7 fps, is at the bottom for comparison. Click a variant to load it on the stage. Each card has its own sliders. replay re-runs the arrive.

Roto outline · painted crawl around the alpha silhouette

Contour from the cutout's alpha channel. Under file://, Chrome taints canvas reads of local images, so the lab first tries a runtime Moore trace and then falls back to a precomputed OpenCV contour (assets/fig-0-contour.js). Strokes are variable-width ribbons. Where a smooth noise field drops below a threshold the width eases to zero, so strokes split, grow and heal continuously, and dry bristle tails run a little past each end.
