v11 lettering lab

Eight typeface and animated-scribble pairs to choose from, on a live night-to-dusk sky. None of them use the noise-displaced outline or drips. Each effect is a reusable module in redesign/assets/lettering/.

Fonts (all SIL Open Font License 1.1): Shippori Mincho B1, Mochiy Pop One, Kaushan Script, DM Serif Display, Shrikhand (Google Fonts), EMS Allure, EMS Nixish (single-line SVG fonts from the Inkscape Hershey Text extension), Relief SingleLine. Textures: Codex (gpt-5.6-terra), see PROMPTS.md. URL options: ?only=3 shows one tile, ?loop=1 starts looping.
