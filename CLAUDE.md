# Shared portfolio handoff

Read [AGENTS.md](AGENTS.md) and [DESIGN-PROGRESS.md](DESIGN-PROGRESS.md) before working on this portfolio, its visual direction, prototypes, assets, or research.

Follow the shared rules in `AGENTS.md`. In particular, updating `DESIGN-PROGRESS.md` is a required part of each relevant task, not an optional follow-up. Update the current state and dated work log after meaningful progress and before handing work back.

During parallel work, have the coordinating agent merge worker reports into the shared handoff. Preserve other agents' updates and keep explicit user choices separate from suggestions.
